# Palette Extractor — определение палитры растрового изображения

Десктопное приложение на **Qt 6 / C++17**, которое находит шесть доминирующих цветов изображения и сохраняет палитру в PNG. Выполнено в рамках учебной практики (СПбГЭТУ «ЛЭТИ», кафедра ИС, 2023).

## Возможности

- Загрузка изображений **PNG, JPG, BMP** любого размера; PNG с прозрачностью обрабатывается корректно.
- Определение **6 самых частых визуально различимых цветов** — близкие оттенки не дублируются.
- Отображение палитры с HEX-кодами рядом с картинкой.
- Экспорт палитры в PNG-файл (вертикальная полоса из блоков 50×25 px):

## Сборка из исходников

Требуется Qt 6 (модуль Widgets) и CMake ≥ 3.16.

```bash
cd palette-extractor/src
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.x/gcc_64
cmake --build build
./build/palette-extractor
```

Либо откройте `src/palette-extractor.pro` в Qt Creator, либо из корня репозитория: `cmake -S . -B build -DBUILD_PALETTE_EXTRACTOR=ON`.

Для проверки можно использовать тестовое изображение [`examples/sunset.png`](examples/sunset.png) — оно даёт палитру со скриншота выше.

## Как это работает

1. **Уменьшение.** Изображение шире 1280 или выше 720 px масштабируется — количество пикселей ограничивается сверху, время работы не зависит от размера файла.
2. **Гистограмма.** Один проход по всем пикселям: `QMap<QString, int>` считает, сколько раз встретился каждый цвет (ключ — HEX-имя цвета).
3. **Отбор.** Цвета перебираются по убыванию частоты. Очередной цвет попадает в палитру, только если он достаточно далёк от всех уже выбранных — иначе шесть оттенков одного неба заняли бы всю палитру.
4. **Расстояние между цветами** — взвешенная евклидова метрика в RGB, учитывающая чувствительность глаза к зелёному:

   ```
   d = √( 0.299·ΔR² + 0.587·ΔG² + 0.114·ΔB² )
   ```

   Порог различимости — `35`.
5. **Экспорт.** Для каждого цвета палитры рисуется блок 50×25 px, блоки складываются в одно изображение и сохраняются через `QImage::save`.

Сложность — **O(w·h)**: меньше, чем один просмотр каждого пикселя, быть не может.
