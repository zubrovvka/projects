# Лабораторная 1 — Сортировочная станция

Перевод арифметического выражения из **инфиксной** записи в **обратную польскую** (постфиксную) с помощью алгоритма сортировочной станции Дейкстры.

## Задача

- Реализовать собственные структуры данных: односвязный список (используется как стек операторов) и динамический массив.
- Разобрать выражение с операциями `+ - * / ^`, функциями `sin` `cos` и скобками.
- Вывести результат в постфиксной форме, используя либо список, либо массив в качестве выходной очереди (выбор в меню).

## Пример

```
$ ./shunting-yard
Enter the given expression (each character separated by a space)
( 1 + 2 ) * sin ( 3 ) - 4 ^ 2 / 5
Working with a List - 0
Working with an array - 1
1
1 2 + 3 sin * 4 2 ^ 5 / -
```

Токены разделяются пробелами — это упрощает лексер и позволяет использовать многозначные числа и имена функций.

## Алгоритм

Приоритеты операций:

| Операция | Приоритет |
|:--------:|:---------:|
| `+` `-` | 0 |
| `*` `/` | 1 |
| `^` | 2 |
| `sin` `cos` | 3 |

Для каждого токена:

```
число        → сразу в выход
оператор op  → пока на вершине стека оператор с приоритетом ≥ op — выталкиваем его в выход;
               затем кладём op на стек
"("          → на стек
")"          → выталкиваем операторы в выход до "(", саму скобку отбрасываем
конец ввода  → выталкиваем всё, что осталось на стеке
```

Сложность — **O(n)** по числу токенов: каждый токен кладётся на стек и снимается с него не более одного раза.

## Структура кода

| Класс | Назначение |
|-------|-----------|
| `List<V>` | односвязный список с вложенным `Node<U>`; методы `push`/`PushBack` (на вершину), `deleteBack`/`deleteStart` (с вершины), `CtrlV` (вставка по индексу), `operator[]` |
| `dynamic_array<V>` | массив с перевыделением памяти при каждом `push_back`; `pop_front`/`pop_back`/`pop_erase` |
| `Operators` | пара «строка операции — приоритет» |

Список используется как стек, поэтому все операции идут через голову — `PushBack` и `deleteBack` по смыслу являются `push` и `pop`.

## Сборка

```bash
g++ -std=c++17 -O2 -o shunting-yard main.cpp
```

или через CMake из корня репозитория.
