# Лабораторная 3 — AVL-дерево

Самобалансирующееся двоичное дерево поиска с интерактивным меню: вставка, поиск, удаление, четыре вида обхода и наглядная печать структуры дерева.

## Пример

```
$ ./avl-tree
Кол-во узлов:
7
Введите элемент: 50
Введите элемент: 30
...

Дерево выглядит следующим образом:
R---50
     L---30
     |   L---20
     |   R---40
     R---70
          L---60
          R---80

~~~~~Программа~~~~~
1. Вставка узла
2. Поиск узла
3. Удаление узла
4. Preorder
5. Inorder
6. Postorder
7. BFS order
8. Выход
```

Проверка балансировки: при вводе `1 2 3 … 15` по возрастанию обычное BST выродилось бы в список, а AVL-дерево остаётся идеально сбалансированным:

```
7           ← BFS order
[8, 4, 12, 2, 6, 10, 14, 1, 3, 5, 7, 9, 11, 13, 15]
```

## Алгоритм

Для каждого узла хранится высота поддерева. После вставки или удаления на обратном пути рекурсии пересчитывается высота и **баланс** — разность высот левого и правого поддеревьев. Если `|баланс| > 1`, выполняется один из четырёх поворотов:

| Ситуация | Условие | Поворот |
|----------|---------|---------|
| Left-Left | правое поддерево тяжелее, у правого ребёнка баланс ≤ 0 | малый левый |
| Right-Left | правое поддерево тяжелее, у правого ребёнка баланс > 0 | правый у ребёнка, затем левый |
| Right-Right | левое поддерево тяжелее, у левого ребёнка баланс ≥ 0 | малый правый |
| Left-Right | левое поддерево тяжелее, у левого ребёнка баланс < 0 | левый у ребёнка, затем правый |

```
   Малый правый поворот              Малый левый поворот

        y                x                 x                  y
       / \              / \               / \                / \
      x   C    ──►     A   y             A   y      ──►     x   C
     / \                  / \               / \            / \
    A   B                B   C             B   C          A   B
```

Удаление узла с двумя детьми — через минимум правого поддерева, после чего дерево балансируется тем же способом.

Все операции — **O(log n)**, высота дерева не превышает `1.44·log₂(n+2)`.

## Обходы

| Меню | Обход | Порядок |
|:----:|-------|---------|
| 4 | Preorder | корень → левое → правое |
| 5 | Inorder | левое → корень → правое (ключи по возрастанию) |
| 6 | Postorder | левое → правое → корень |
| 7 | BFS | по уровням; вместо `std::queue` используется собственный `List<T>` |

## Структура кода

| Файл | Содержимое |
|------|-----------|
| `main.cpp` | класс `AVLtree` (вставка, удаление, повороты, обходы, `printHelper`) и меню |
| `list.h` / `list.tpp` | шаблонный односвязный список `List<T>` с `operator[]`, `insert`, `pop`, поддержкой отрицательных индексов и вывода в поток. Реализация шаблона вынесена в `.tpp` и подключается из заголовка |

## Сборка

```bash
g++ -std=c++17 -O2 -o avl-tree main.cpp
```

или через CMake из корня репозитория.
