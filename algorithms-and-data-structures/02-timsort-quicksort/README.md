# Лабораторная 2 — TimSort и QuickSort

Реализация двух алгоритмов сортировки с нуля и сравнение времени их работы.

## Задача

- Реализовать **TimSort** — гибрид сортировки вставками и слияния, используемый в Python и Java.
- Реализовать **QuickSort** (схема Хоара с опорным элементом в середине).
- Заполнить массив вручную или случайными числами, отсортировать выбранным алгоритмом и вывести затраченное время.

## Алгоритмы

### TimSort

1. **minrun.** Из длины массива `n` вычисляется размер минимального подмассива (от 32 до 64): берутся старшие 6 бит `n`, и к ним прибавляется 1, если среди отброшенных битов был хотя бы один ненулевой.
2. **Runs.** Массив режется на куски длиной `minrun`, каждый сортируется вставками — на коротких массивах она быстрее всего.
3. **Слияние.** Соседние отсортированные куски попарно сливаются, размер блока удваивается, пока не останется один блок.

В упрощённом варианте (как здесь) не выполняется поиск естественных упорядоченных последовательностей и «галоп», поэтому алгоритм ведёт себя как сортировка слиянием с ускоренной базой рекурсии.

### QuickSort

Классическое разделение Хоара: два индекса идут навстречу друг другу, элементы меньше опорного оказываются слева, больше — справа, затем рекурсия для обеих частей. Сортировка выполняется **на месте**, без копирования массива.

| Алгоритм | Среднее | Худшее | Память | Устойчивость |
|----------|:-------:|:------:|:------:|:------------:|
| TimSort | O(n log n) | O(n log n) | O(n) | да |
| QuickSort | O(n log n) | O(n²) | O(log n) стек | нет |
