# Алгоритмы и структуры данных

Работы по курсу «Алгоритмы и структуры данных». Общее требование ко всем работам — **не использовать контейнеры STL** для основной структуры данных: списки, стеки, очереди, динамические массивы и деревья реализованы вручную.

| Работа | Папка | Структуры данных | Алгоритмы |
|--------|-------|------------------|-----------|
| Лабораторная 1 | [`01-shunting-yard/`](01-shunting-yard/) | односвязный список (стек), динамический массив | сортировочная станция Дейкстры |
| Лабораторная 2 | [`02-timsort-quicksort/`](02-timsort-quicksort/) | массив | TimSort, QuickSort, сортировка вставками, слияние |
| Лабораторная 3 | [`03-avl-tree/`](03-avl-tree/) | AVL-дерево, односвязный список | балансировка поворотами, обходы DFS/BFS |
| Курсовая работа | [`coursework-graph-mst/`](coursework-graph-mst/) | матрица смежности, очередь, DSU | DFS, BFS, алгоритм Крускала |

## Сборка

Из корня репозитория:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Или любую работу отдельно, без CMake:

```bash
g++ -std=c++17 -O2 -o shunting-yard 01-shunting-yard/main.cpp
```

Все программы интерактивные: читают данные с клавиатуры через меню. Под Windows после завершения вызывается `pause`, на других системах — нет.
